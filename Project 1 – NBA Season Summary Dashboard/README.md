# 🏀 NBA Season Summary Dashboard
**Tools:** Excel • Tableau  
**Domain:** Sports Analytics

## 📌 Overview
This dashboard provides a season-level summary of NBA player performance, including scoring, efficiency, and game-by-game trends. It is designed for quick insights into player consistency and overall contribution.

## 📂 Files Included
- data/ — raw and cleaned Excel files  
- dashboard/ — PDF, PNG, TWBX  
- README.md — documentation  

## 🔍 Process
1. Cleaned raw NBA data in Excel  
2. Created season-level aggregates  
3. Imported data into Tableau  
4. Built interactive charts with filters and tooltips  
5. Designed dashboard layout
