# 📈 Player Scoring Trend Analysis
**Tools:** Python (pandas, matplotlib)  
**Domain:** Sports Analytics

## 📌 Overview
This project analyzes scoring trends for NBA players across the season, identifying hot streaks, cold streaks, and overall consistency.

## 📂 Files Included
- data/ — raw CSV files  
- code/ — Python scripts  
- dashboard/ — exported charts  
- README.md  

## 🔍 Process
1. Loaded game logs using pandas  
2. Cleaned and formatted scoring data  
3. Calculated rolling averages  
4. Visualized scoring trends with matplotlib  
5. Exported charts for dashboard use
