# 🔥 Shot Distribution Heatmap
**Tools:** Python (nba_api, pandas, seaborn)  
**Domain:** Sports Analytics

## 📌 Overview
This project visualizes a player's shot tendencies using a heatmap generated from nba_api shot location data.

## 📂 Files Included
- data/ — shot data pulled from nba_api  
- code/ — Python scripts  
- dashboard/ — heatmap images  
- README.md  

## 🔍 Process
1. Pulled shot data using nba_api  
2. Cleaned and filtered shot coordinates  
3. Created heatmap using seaborn  
4. Exported visuals for dashboards
