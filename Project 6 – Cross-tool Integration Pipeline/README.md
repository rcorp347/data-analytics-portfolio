# 🔗 Cross-tool Integration Pipeline
**Tools:** Python • SQL • Tableau  
**Domain:** Multi-tool Workflow

## 📌 Overview
This project demonstrates an end-to-end data pipeline connecting Python, SQL, and Tableau to automate cleaning, transformation, and dashboard refresh.

## 📂 Files Included
- data/ — raw and cleaned datasets  
- code/ — Python + SQL scripts  
- dashboard/ — Tableau files  
- README.md  

## 🔍 Process
1. Cleaned raw data using Python  
2. Loaded cleaned data into SQL tables  
3. Built SQL transformations  
4. Connected SQL to Tableau  
5. Automated refresh workflow  

## 🧠 Key Insights
- Multi-tool pipelines improve efficiency  
- SQL + Python combination is powerful  
- Tableau provides final visualization layer  

## 🛠 Skills Demonstrated
- ETL pipeline design  
- SQL + Python integration  
- Tableau automation
